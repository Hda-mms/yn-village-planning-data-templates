# 云南省村庄规划数据填写模板

本仓库提供云南省村庄规划动态调整所需的空白矢量模板、字段填写说明、使用单 Markdown 模板、地类对照表和提交前自检清单。仓库不含真实行政区、项目、个人或成果数据。

## 一键下载

- [下载全部模板与填写说明（ZIP）](https://github.com/Hda-mms/yn-village-planning-data-templates/archive/refs/heads/master.zip)
- [先阅读使用说明](00_使用说明.md)
- [填写完成自检清单](05_填写完成自检清单.md)

ZIP 由 GitHub 根据 `master` 分支自动生成，包含本仓库当前全部空白矢量和填写说明；仓库不单独存放版本 ZIP 文件。

## 文件内容

- `01_GHDLTBTZ`：GHDLTBTZ 规划地类调整面图层，提供 33、34、35 带空白 SHP 及字段填写说明；
- `02_增减挂钩项目建新区_涉152`：涉 152 建新区面图层，提供 33、34、35 带空白 SHP 及字段填写说明；
- `03_使用单_涉152`：使用单 Markdown 空白模板、填写说明、扫描件转 Markdown 的多模态提示词和隐私门禁；
- `04_对照表`：2023 年版用地用海分类名称—编码表及 FHQX、305 号情形说明；
- `05_填写完成自检清单.md`：提交前逐项检查表；
- `00_使用说明.md`：模板选择和填写顺序说明。

## 使用原则

请复制所需的完整 SHP 侧车文件到自己的工作目录，按说明填写后逐项自检。不要修改字段名、字段类型、字段长度、文件名或坐标带。填写完成的真实资料不得回传本仓库。

所有矢量模板均为零要素空模板；每套 `.shp/.shx/.dbf/.prj/.cpg` 文件必须成套保留。
