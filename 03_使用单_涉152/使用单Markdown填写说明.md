# 使用单 Markdown 填写说明

1. 原 PDF 每一页视为一张独立使用单；每页使用一个 `##` 二级标题，不得跨页合并字段。
2. 每页必须有六个字段：`ZJGGJYZBLYLX`、`ZJGGJYZBSYDBH`、`ZBLYXMMC`、`YSWH`、`JYZBZGM`、`JXFAMC`。
3. `JYZBZGM` 必须把数值和原件单位写在同一单元格，例如 `0.1785亩` 或 `119.00平方米`。
4. `JXFAMC` 只填写方案全称本身，不要带“[建新方案]用于”等表头引导语。
5. 单个项目各页 `JXFAMC` 必须一致；不同使用单编号不得合并。
6. 原件明确写“本县/跨县”时原样填写；原件只写“建新方案”且未明确来源类型时不要猜测，可原样填写“建新方案”。
7. 看不清、缺项或内容冲突时写“无法确认”，先核对原件。
8. 不需要也不允许把 JSON 作为填写内容。

扫描型 PDF 无法可靠读取时，优先使用单位批准的本地 OCR 或本地多模态 AI。只有资料允许外发、已按要求裁剪或脱敏，并确认所用服务满足单位的数据留存、训练使用和地域要求后，才可以使用外部对话 AI。AI 输出的 Markdown 保存为 `.md` 后再核对。
