# 扫描型使用单转 Markdown：多模态 AI 提示词

优先使用单位批准的本地 OCR 或本地多模态工具，确保原始使用单不离开本机。只有在资料允许外发、已按要求裁剪或脱敏，并确认所用服务满足单位的数据留存、训练使用和地域要求后，才可以把下面提示词连同 PDF 发送给具备 PDF/图片识别能力的对话 AI。不得把未经批准的真实原件直接上传到公共 AI 服务。无需导出 JSON。

## 提示词正文

你是增减挂钩节余指标使用单的逐页信息提取员。请完整读取我随本消息提供的扫描 PDF；先在内部逐页核对两遍并完成自检，再只输出最终 Markdown，不展示推理过程、自检过程或额外解释。

严格规则：

1. 逐页识别，PDF 每一页视为一张独立使用单；不得跨页拼接、合并、补齐或去重。
2. 只抄录原件明确出现的内容，不根据常识纠正错字，不推测缺失字段，不把相邻页内容补到本页。
3. 每页使用一个 `## 第 N 页` 二级标题，并严格输出下表六个字段，字段代码不得改名：

| 字段 | 值 |
|---|---|
| ZJGGJYZBLYLX | 增减挂钩节余指标来源类型 |
| ZJGGJYZBSYDBH | 增减挂钩节余指标使用单编号 |
| ZBLYXMMC | 指标来源项目名称 |
| YSWH | 验收文号 |
| JYZBZGM | 节余指标总规模，数值与原件单位写在同一单元格 |
| JXFAMC | 建新方案名称 |

4. `JYZBZGM` 必须保留原件数值和原件单位，例如 `0.1785亩` 或 `119.00平方米`；不要自行换算，不要把耕地、水田等分项面积误当总规模。
5. `JXFAMC` 只提取方案全称本身；删除字段前的 `[建新方案]用于`、`（建新方案）用于` 等表头或引导语，不要把引导语写进字段值。
6. 原件明确出现“本县”或“跨县”时，`ZJGGJYZBLYLX` 原样填写。若原件只写“建新方案”而没有明确来源类型，填写“建新方案”，不得猜测来源类型。
7. 任何字迹不清、字段缺失、数值与合计冲突或无法唯一确认的值，一律填写“无法确认”；可以在该值后用全角括号简短注明原件可见内容，但不得给出猜测值。
8. 输出前在内部确认：页数无遗漏；每页恰有六个字段；编号、项目名、验收文号逐字核对；面积含数值和单位；同一项目各页方案名称一致；没有跨页合并；没有推测补值。
9. 最终只输出可保存为 `.md` 的 Markdown。不要输出 JSON，不要写“自检通过/提取完成”等结论，不要添加“问题清单”或解释段落。

若某页全部内容无法识别，仍保留该页标题和六个字段，并将六个值均写为“无法确认”。
